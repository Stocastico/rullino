Web-ready export

Resize a set of photos to a long side (in linear light, which keeps edges and colours right), sharpen them a little for screens and save them as JPEG, WebP or PNG. Nothing is uploaded: the photos are processed on this device. Location (GPS), camera and other metadata are not kept in the exported files.
