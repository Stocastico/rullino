Compare two renders

Two images of the same size, compared channel by channel (alpha included): the largest difference, how many pixels go beyond a tolerance, and a map of where. Useful to check that a preview and a server render agree, or what a new version changed. Nothing is uploaded.

The same in your code

rullino's own promise is stated in linear light, per filter: see the parity table. To check two renders of your own in a test:

import { compareImages, decodeSrgb8 } from '@rullino/core';

// a and b: 8-bit RGBA pixels of one size (ImageData, or a decoder's output)
const lin = (img) => decodeSrgb8(img.data, img.width, img.height);
const { pass, worst, outliers } = compareImages(lin(a), lin(b), { abs: 4e-3, rel: 4e-3 });
