# rullino wiki

**rullino** describes a photo edit once, as JSON, and renders it on the GPU in the browser, on the CPU in a worker, or in Node and from the command line, with output that agrees within a [published per-filter tolerance](https://github.com/Stocastico/rullino/blob/main/docs/parity.md). MIT, TypeScript, zero runtime dependencies, **everything on your machine**.

- **Try it**: the [playground](https://stefanomasneri.com/rullino/) (your photo never leaves the browser).
- **Use it**: [Getting started](https://github.com/Stocastico/rullino/blob/main/docs/getting-started.md) · [Concepts](https://github.com/Stocastico/rullino/blob/main/docs/concepts.md) · [The edit document](https://github.com/Stocastico/rullino/blob/main/docs/edit-document.md) · [Troubleshooting](https://github.com/Stocastico/rullino/blob/main/docs/troubleshooting.md) · [API reference](https://stefanomasneri.com/rullino/docs/).
- **Where it is going**: [[Roadmap]] (0.8 → 1.0: a client-side imaging platform).
- **How it works**: [[Architecture]].
- **Questions**: [[FAQ]], then [Discussions](https://github.com/Stocastico/rullino/discussions).
- **Contributing**: [[Contributing]].
